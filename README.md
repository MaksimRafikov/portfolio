# Сайт-портфолио — Максим Рафиков

Личный сайт, который показывают на встречах и кидают ссылкой заказчику.
Не для SEO и не для рекламы: страница закрыта от индексации (`noindex`).

Статика: чистый HTML + CSS, JS — две мелочи (линейка под шапкой, подсветка раздела в меню).
Сборка не нужна, зависимостей нет.

## Как открыть локально

Самый простой способ — открыть `index.html` двойным кликом, браузер покажет сайт как есть.

Если нужен «честный» локальный адрес (например, посмотреть с телефона в той же сети):

```powershell
cd "c:\Users\Пользователь\Desktop\Coursor\сайт-портфолио"
python -m http.server 5173
```

Дальше — `http://localhost:5173` в браузере.

Шрифты (Source Serif 4, Golos Text, IBM Plex Mono) подгружаются с Google Fonts.
Без интернета сайт откроется на запасных шрифтах — вёрстка не ломается,
но перед показом на встрече лучше один раз открыть страницу с сетью.

## Дизайн-система

Все решения — в блоке токенов в начале `assets/css/site.css`. Менять цвета, шрифты и
отступы нужно там, а не в отдельных правилах.

- **Цвет.** Тёплая бумага `--paper` `#f8f6f1`, чернила `--ink` `#16181b`,
  единственный акцент `--accent` `#a6431e` (жжёная сиена) — только для цифр
  результата и активных состояний.
- **Шрифты.** Заголовки — Source Serif 4 (`--font-display`), текст — Golos Text
  (`--font-body`), цифры и служебные метки — IBM Plex Mono (`--font-mono`).
- **Размеры.** Через `clamp()`, поэтому отдельных мобильных медиазапросов на
  типографику нет.
- **Отступы.** Шкала `--space-3xs … --space-3xl`, вертикальный ритм секций — `--space-2xl`.
- **Вёрстка.** Mobile-first: базовые стили — телефон, брейкпоинты `46rem` и `62rem`.

Сознательно не используется: градиенты, glassmorphism, карточки с тенями, эмодзи,
придуманная статистика, Inter/Roboto.

## Правила по контенту

- Цифры — только из `КЕЙСЫ_ДЛЯ_САЙТА_И_БИРЖ.md` (папка `Портфолио для бирж`).
  Ничего не округлять «для красоты» и не выдумывать.
- Не публиковать: имена клиентов без согласия, таблицы с живыми email и телефонами,
  логины, токены ботов.
