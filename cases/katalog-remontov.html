Что сделал

Сайт-каталог: объекты по жилым комплексам, фото, описание работ, видео эксперта. Фото защищены водяным знаком. Новые кейсы добавляются по понятному сценарию, без тяжёлой админки.

Что на выходе

  • Публичный каталог, который можно открыть на встрече
  • Фильтр по ЖК, фото до/после, планы, видео
  • Защита изображений водяным знаком

Стек: HTML, CSS, JavaScript, Python для обработки фото, GitHub Pages.
