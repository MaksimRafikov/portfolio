Telegram bot for tasks and payment reminders

For a manager, accountant, or lead: remember deadlines and payments without a heavy CRM — write the task in plain words, the bot reminds you.

Status
working MVP

What I built

You message the bot a task in plain words: “tomorrow at 9:00 call”. It reminds you, you can snooze 15 minutes or a day, mark done, set a daily / weekly / monthly repeat. Understands Russian dates. No separate server required.

What you get

  • Create task → reminder → done
  • Buttons “done / 15 min / 1 hour / tomorrow”
  • Repeats: day, week, month
  • Free-form date input in Russian
