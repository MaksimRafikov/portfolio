What I built

A layer between YClients and day-to-day salon work. Clients land in “core / newcomers / growing / at-risk / dormant” — hold, push, grow, win back, do not spend.

The owner checks core share and risks in minutes; the manager exports lists; the front desk calls a short list. Live data stays at the salon; the website is a public playground before a pilot call.

What the salon gets

  • Dashboard with KPIs, segments, and a weekly action plan
  • Call lists, no-shows, Excel export
  • Install on the salon PC — the base does not go to a third-party analytics cloud
  • YClients read-only; CRM labels optional

The demo site uses fictional M-Salon data only — no real names or phones.
