Which clients to call this week

What I built

Connected visit records and segmented clients: core, newcomers, at-risk. The owner sees the picture, the manager sees the shift, the sales person gets a ready call list. Data is read-only: the program does not change salon records itself.

What you get

  • Segments “core / newcomers / at-risk”
  • Call lists and a no-show report
  • Weekly report
  • Install pack for Windows and macOS — without publishing the database online

Salon name and client phones are not published. Sales demos for others use synthetic figures only under the “Your beauty salon” brand.
